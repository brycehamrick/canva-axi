# Project agent memory

- This is an AXI CLI wrapping Canva's **remote MCP server** (`https://mcp.canva.com/mcp`) — not the REST API. Every capability routes through an MCP `tools/call`; the tool names and response shapes are documented at https://www.canva.dev/docs/apps/mcp/tools/ (one page per tool).
- OAuth 2.0 + Dynamic Client Registration against `https://mcp.canva.com` (verified live: discovery at `/.well-known/oauth-authorization-server`, register `/register`, token `/token`, PKCE S256, `token_endpoint_auth_method: none`). All 16 advertised scopes are requested at login. Tokens live in `$XDG_CONFIG_HOME/canva-axi/config.json` (0600). `CANVA_ACCESS_TOKEN` env overrides for CI.
- Architecture follows walter-axi (same pattern: remote MCP + DCR OAuth + loopback PKCE + axi-sdk-js): `src/canva/{oauth,loopback,config,client}.ts`, `src/commands/*`, `src/render.ts` (view shaping), `src/skill.ts` (single source of guidance). Client sessions open per call via `StreamableHTTPClientTransport` and close in `finally` — nothing resident.
- MCP quirks encoded in `client.ts`: three job flavors (server-wrapped `job{status,result}`; client-polled `job_id`+`continuation_token`+`polling_policy.wait_seconds` with `polled_too_early`; image jobs `PENDING/SUCCESS/FAILURE` via `jobId`); `get-assets` returns one content block per id (multi-text-block envelopes merge under `blocks`); Pro-plan tools return empty results instead of errors on Free plans.
- Safety contract: reads/polls/exports and the draft half of editing (start/perform/cancel) are ungated; everything persisting or spending AI credits requires `--confirm` and throws VALIDATION_ERROR (exit 2) **before any network call**. No design-delete exists in the Canva MCP surface. `merge --op delete_pages` is permanent and flagged in help.
- Tests never touch the network: handlers take `{ createApi }` deps; `RawToolCaller` fakes return real MCP envelope shapes. `npm test` runs vitest; `npm run skill:check` guards SKILL.md drift (regenerate with `npm run skill:gen` after changing `src/skill.ts`).
- TOON 4.x: return plain arrays of uniform-keyed records — the encoder infers `key[N]{fields}:` rows automatically. Heterogeneous keys fall back to verbose object rows, so always include optional fields as `""`.
- `canva-axi tools --schema <name>` surfaces the live server input schema — when a call rejects arguments, point agents there instead of guessing (the server owns the schemas; the CLI hardcodes the command surface).
- Design refs (D…) and full share URLs are accepted everywhere via `normalizeDesignId`; shortlinks resolve via `canva-axi shortlink` first.
- Note: `ardaatahan/canva-axi` already exists in the axi.md catalog as a REST API wrapper; ours is the MCP wrapper (different approach, same name was free on npm on 2026-11-08). When contributing to the catalog, follow https://github.com/kunchenguid/axi/blob/main/CONTRIBUTING.md — human PRs to main must go through no-mistakes; catalog entries are added to `catalog.yaml` then `pnpm run docs:gen`.
